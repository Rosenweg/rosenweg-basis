# Rosenweg Bausteine (Beispiel)

Beispiel-App für `rosenweg_basis`: Rechte, Listen, Formulare, Scannen,
Dateien und PDF – ohne Anmeldung, mit Vorführdaten (`lib/attrappe.dart`).

```sh
flutter run -d macos             # oder linux, windows, Android-/iOS-Gerät
BEISPIEL_ZIEL=5 flutter run -d linux   # gleich die PDF-Seite (0 Rechte … 5 PDF)
```

Berechtigungen (Kamera, Dateien) sind hier eingetragen und dienen als Muster
für neue Apps – siehe README der Basis, „Was jede App einrichten muss“.
