# Herkunft der Zeichen

Die Zeichen in diesem Ordner stehen rechts unten in der weissen Plakette der App-Logos
(`../baukasten.py`).

| Zeichen | Herkunft | Lizenz |
|---|---|---|
| `dateien`, `diktiergeraet`, `dokumente`, `fernseher`, `galerie`, `geraet`, `kalender`, `kamera`, `karten`, `kontakte`, `malen`, `messenger`, `monitor`, `notizen`, `person`, `rechner`, `startbildschirm`, `tastatur`, `telefon`, `uhr` | eigene Zeichnungen (Rosenweg) | GPL-3.0-or-later wie das Repo |
| `noc`, `rundmail`, `ssh`, `tv`, `zutritt` | eigene Zeichnungen (Rosenweg), 27.11.2026 neu statt Material Symbols, damit sie bei 48 px nicht mit Apps derselben Gruppe verwechselt werden; `zutritt` trägt seit Karten in Zutritt aufging links unten die Karte aus `karten` | GPL-3.0-or-later wie das Repo |
| `salz` | eigene Zeichnung, aus Rosenweg/rosenweg-salz `assets/logo/zeichen/salz.svg` | GPL-3.0-or-later |
| `stationen` | eigene Zeichnung, aus Rosenweg/os-stationen `docs/logo-zeichen.svg` (daraus ist dort `docs/logo.svg` gebaut; der Baukasten ergibt mit diesem Zeichen genau dieses Logo) | GPL-3.0-or-later |
| alle übrigen (Flutter-Apps aus `../flutter-apps.txt`) | zusammengesetzt mit `../zeichen-zusammensetzen.py` aus **Material Symbols** (Rounded, gefüllt, Strichstärke 600) von Google; welches Symbol, steht als Kommentar in jeder Datei | Apache License 2.0 |

weissem Rand). Keine Marken- oder Firmenzeichen (z. B. kein WhatsApp-Logo: Rosenweg WhatsApp
trägt eine Sprechblase mit Zahnrad).
